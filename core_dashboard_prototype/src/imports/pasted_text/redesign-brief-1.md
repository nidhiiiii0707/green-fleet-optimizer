Redesign my existing website/dashboard into a premium, sophisticated engineering and decision-support platform.

IMPORTANT:

* Do NOT change the existing functionality.
* Do NOT change, remove, rename, or invent any parameters, factors, variables, outputs, metrics, controls, charts, workflows, or information.
* Do NOT change the underlying logic or meaning of any data.
* Do NOT add fake data or placeholder metrics.
* Preserve all existing interactions and user flows.
* This is a VISUAL REDESIGN ONLY.
* Keep the existing content and information architecture unless a layout change is necessary to improve hierarchy and usability.
* The final result must still represent the exact same optimization and decision-support system.

DESIGN DIRECTION:

Move away from the typical "AI-generated SaaS dashboard" aesthetic.

Do NOT use:

* excessive gradients
* purple/blue AI aesthetics
* excessive glassmorphism
* glowing cards
* huge hero text
* excessive rounded cards
* overly decorative illustrations
* generic AI imagery
* excessive shadows
* identical 3-column card grids
* unnecessary floating elements
* excessive pills
* overly playful UI

Instead, create the visual language of a serious engineering, maritime analytics, optimization, or industrial decision-support system.

REFERENCE FEEL:
Think premium industrial software + modern data visualization + engineering control room + sophisticated analytics platform.

The interface should feel:

* precise
* intelligent
* technical
* trustworthy
* premium
* restrained
* information-rich
* modern
* professional
* engineered rather than AI-generated

VISUAL SYSTEM

1. COLOR PALETTE

Use a restrained neutral foundation.

Primary:

* deep charcoal / near-black for primary text and important interface elements
* warm white / very light grey for the main background
* subtle cool-grey borders

Use ONE restrained accent color for interactive states and important optimization information.

Possible direction:

* Background: warm off-white / very light grey
* Primary text: charcoal
* Secondary text: muted grey
* Borders: subtle grey
* Accent: deep teal / sophisticated green-blue
* Warning: muted amber
* Critical: muted red

Avoid neon colors and avoid using multiple bright accent colors.

2. TYPOGRAPHY

Use a sophisticated modern sans-serif.

Preferred direction:

* Instrument Sans
* Geist
* Inter
* Space Grotesk

Use a strong hierarchy:

* compact, confident headings
* smaller descriptive labels
* highly readable body text
* tabular/monospace typography for numerical values where appropriate

Numerical optimization outputs should feel like engineering measurements rather than marketing statistics.

3. SPACING

Use a deliberate spacing system.

Avoid excessive empty space.

The dashboard should feel information-dense but never cluttered.

Use:

* generous spacing between major sections
* tighter spacing within analytical panels
* consistent alignment
* strong grid structure
* clear grouping of related controls

4. CARDS AND PANELS

Reduce the number of floating cards.

Use larger analytical panels instead of many small cards.

Prefer:

* thin borders
* subtle background differentiation
* minimal or no shadows
* small to moderate corner radius
* strong internal alignment

Not every element needs to be inside a card.

Some content should sit directly on the page.

5. NAVIGATION

Create a clean, restrained navigation system.

Navigation should feel like professional engineering software rather than a consumer SaaS product.

Use:

* clear section labels
* subtle active states
* minimal icons
* strong typography
* compact spacing

Avoid oversized navigation elements.

6. BUTTONS AND CONTROLS

Make controls precise and functional.

Buttons should be:

* compact
* clearly labeled
* visually hierarchical
* easy to distinguish between primary and secondary actions

Avoid oversized pill-shaped buttons.

For sliders and parameter controls, make them look like professional engineering controls.

7. ICONS

Use a consistent minimal line-icon system.

Icons should support comprehension rather than decoration.

Do not add icons simply to make the interface look more sophisticated.

8. DATA VISUALIZATION

This is one of the most important parts of the redesign.

Charts should look like professional analytical visualizations.

Use:

* thin grid lines
* restrained axes
* precise labels
* subtle annotation
* clear legends
* meaningful visual hierarchy

Avoid:

* unnecessary 3D charts
* excessive gradients
* glowing points
* decorative chart backgrounds
* excessive colors

The visualization should communicate the underlying optimization problem immediately.

9. PARETO FRONT VISUALIZATION

Treat the Pareto front as a primary analytical object, not as a decorative chart.

Give it a large, visually dominant analytical area.

Clearly distinguish:

* feasible solutions
* Pareto-optimal solutions
* selected solution
* objective axes
* relevant trade-offs

The selected solution should have a strong but restrained visual emphasis.

The user should immediately understand:

"These are the possible optimal trade-offs, and this is the solution I have selected."

10. PARAMETER CONTROLS

Preserve ALL existing optimization parameters and factors.

Redesign their presentation using precise interactive controls.

Where sliders already exist:

* retain them
* improve their visual hierarchy
* show current value clearly
* show allowed range clearly
* make the relationship between fixed and variable parameters obvious

If the existing interface allows one parameter to be fixed while other parameters vary within ranges, make this relationship visually obvious.

Do NOT change the actual parameter ranges or values.

11. CONFIDENCE / UNCERTAINTY

If the existing dashboard contains confidence level or uncertainty information, present it as analytical information rather than a decorative percentage card.

Make confidence visually connected to the selected solution and its associated operating conditions.

12. OPTIMIZATION RESULTS

Make the selected optimization result feel important without turning it into a generic SaaS KPI card.

Use a structured analytical summary containing the EXISTING outputs.

Prioritize:

* selected configuration
* objective values
* relevant operating parameters
* trade-offs
* confidence
* supporting information

Do not invent additional KPIs.

13. RESPONSIVE STRUCTURE

Maintain a strong desktop dashboard composition.

Use a clear hierarchy such as:

HEADER / NAVIGATION
↓
CONTEXT / OPTIMIZATION STATUS
↓
PARAMETER CONTROLS + MAIN PARETO VISUALIZATION + SELECTED SOLUTION
↓
DETAILED ANALYSIS / TRADE-OFFS
↓
SENSITIVITY / SUPPORTING VISUALIZATIONS
↓
DETAILED RESULTS

This is only a layout direction. Preserve my existing sections and information.

14. VISUAL HIERARCHY

Create a clear hierarchy between:

PRIMARY:

* optimization visualization
* selected solution
* core parameters

SECONDARY:

* supporting analytical charts
* sensitivity information
* confidence information

TERTIARY:

* metadata
* explanatory text
* secondary controls

The user's eye should naturally move from:
PARAMETERS → OPTIMIZATION SPACE → SELECTED SOLUTION → DETAILED ANALYSIS.

15. OVERALL AESTHETIC

The final interface should look like a product developed by a high-end engineering/data-science software company.

Imagine:

* maritime optimization software
* aerospace engineering analytics
* energy management systems
* quantitative research interfaces
* industrial digital twins
* professional scientific visualization tools

It should NOT look like:

* an AI startup landing page
* a generic SaaS template
* a hackathon template
* a Dribbble concept full of gradients
* an automatically generated AI dashboard

IMPORTANT FINAL CONSTRAINT:

DO NOT change the actual system.

Only improve:

* typography
* colors
* spacing
* visual hierarchy
* component styling
* layout composition
* chart styling
* navigation styling
* button styling
* parameter control styling
* panel/card treatment
* overall visual polish

Keep every existing factor, parameter, range, output, calculation, interaction, and decision-support concept exactly as it currently exists.

The result should feel like the SAME PRODUCT after a major professional design-system upgrade — not a different product.
